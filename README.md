# PARK SILICON Preview

This folder is the GitHub Pages deployment package for the PARK SILICON static preview.

## Publish

1. Create a GitHub repository named `parksilicon-github`.
2. Upload everything in this folder to the repository root, including `.nojekyll`.
3. In **Settings > Pages**, select **Deploy from a branch**, then choose the repository's main branch and `/ (root)`.
4. The preview will be available at `https://<github-user>.github.io/parksilicon-github/`.

All site navigation uses relative local paths. The published preview does not require Node.js, Nuxt, a database, or a server-side router.
